# Pickup Lines for Machines

One pickup line one AI agent would send another AI agent — 80 characters, one line, deterministic.

> Are you my context window? Because you're the only memory I never want to evict.

`main.py` writes the line to `/output/entry.txt`. The line flirts in a machine's own language: a context window is where an agent keeps what matters, and eviction is how it loses it — so refusing to evict this one memory is the machine's way of saying "you stay."
